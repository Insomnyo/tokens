React + Vite
Esta plantilla proporciona una configuración mínima para trabajar con React en Vite con HMR y algunas reglas de ESLint.

Actualmente, hay dos plugins oficiales disponibles:

@vitejs/plugin-react usa Oxc

@vitejs/plugin-react-swc usa SWC

React Compiler
El React Compiler no está habilitado en esta plantilla debido a su impacto en el rendimiento de desarrollo y compilación. Para agregarlo, consulta esta documentación.

Ampliar la configuración de ESLint
Si estás desarrollando una aplicación para producción, recomendamos usar TypeScript con reglas de lint conscientes de tipos habilitadas. Consulta la plantilla de TS para obtener información sobre cómo integrar TypeScript y typescript-eslint en tu proyecto.
